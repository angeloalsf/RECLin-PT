\chapter[Busca do limiar do Two-Stage]{Busca do limiar do Two-Stage}
\label{ap:tau}

A Tabela~\ref{tab:tau_encoders} reproduz a busca completa do limiar $\tau$ do
Two-Stage no DEV para os três \emph{encoders}, registrada no arquivo de congelamento
do limiar de cada composição. Para cada valor da grade, o \emph{pipeline} completo foi
executado pelo fluxo real, com o estágio 2 aplicado só aos pares roteados. O critério
do protocolo é o maior F1 de \texttt{negation\_of}, com desempate pelo macro-F1, e foi
o mesmo para os três \emph{encoders}. Esses valores foram usados para a escolha de
$\tau$ e são, por isso, otimistas como estimativa de desempenho.
